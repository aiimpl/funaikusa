### 1-3. 能島城のつくり

- 島全体を3段に削って、本丸・二の丸・三の丸を階段のように置き、東の隅と南の隅に出丸を置いた [愛媛県]
- 「二の丸が本丸を囲み、東に三の丸、南端に東南出丸、東端に矢櫃と呼ばれる小曲輪」[美術展]。曲輪は全部で6つとする資料もある。1つの曲輪に「100〜200人ほどの兵」が入れた [城びと]
- 鯛崎島も頂上を削って出丸にしていた [愛媛県]
- **建物**：三の丸に「唯一の礎石建物である大型の建造物」（倉と推定）。二の丸に「合わせて9棟の掘立柱建物跡」。本丸に「小さな掘立柱建物」（物見やぐらと推定）[美術展]
- **鍛冶**：三の丸で鍛冶の跡が見つかり、釘や矢じりが出た [美術展]
- **出土品**：高級な陶磁器、備前焼の大甕、本丸からかわらけ1万点以上、東南出丸から中国の銭82枚 [美術展]
- **船だまり**：北側の砂浜。「潮流が緩やかなので、対外的な窓口としての主要な船着き場」[美術展]
- **岩礁ピット**（岩場に彫った柱の穴）：
  - 数は約380個 [愛媛県]、400以上 [城びと]、約460個 [検索:ピット] と資料によって違う
  - 北側の船だまりと東の海岸に多い。「船などをつなぐための柱を立てた」と考えられている [美術展]
  - 桟橋や護岸の杭の列、船をつなぐ柱の跡。直径1 m・深さ2 mの大きな穴が2つある [城びと]
  - 引き潮のときに丸い柱の穴が見える [今治観光協会]
- **石垣**：防御のための石垣は資料に出てこない [美術展]。石積みはあるが、「岩礁ピットに伴うものか、それより後世のものであるのか判断できていない」[検索:ピット]。→ **土と木の城で、高い石垣はない**として作るのがよい
- **使われた時期**：14世紀中ごろ〜後半から16世紀後半まで。南側の作業場は15〜16世紀に段階的に埋め立てられた [検索:ピット] [城びと]。江戸時代からは無人島 [検索:ピット]
- 東の海岸の発掘では、砂浜から約500点の遺物が出たが、通路などの遺構は見つからなかった。「海蝕テラス」と「岩礁ピット」が記録されている [奈文研]

### 1-4. まわりの瀬戸

- **宮窪瀬戸**：大島と伯方島の間。能島のまわりの潮は最大10ノット（時速約18 km）[いよ観] [検索:宮窪]。大潮のときは9ノット以上で流れる [検索:宮窪]
- **船折瀬戸**：伯方島と鵜島の間、幅約300 m。最大8ノット（時速約15 km）。満ち潮と引き潮で流れる向きが変わる [W船折瀬戸]

## 2. 潮の流れ

| 項目 | 値 | 出典 |
|---|---|---|
| 宮窪瀬戸（能島のまわり）の最大 | 10ノット（時速約18 km） | [いよ観] [美術展] |
| 船折瀬戸の最大 | 8ノット（時速約15 km） | [W船折瀬戸] |
| 来島海峡の最大 | 10ノット | [W来島] |
| 来島海峡の実験で使った値 | 北へ流れるとき7ノット、南へ流れるとき6ノット | [JINNAVI] |
| 向きが変わる回数 | 1日に多いときで4回 | [JINNAVI] [W来島] |
| 潮の周期 | 干潮から次の干潮まで平均約12時間25分 | [W潮汐] |

- 流れの向きは約6時間12分ごとに変わる（周期の半分）。1日に4回、流れが止まる（転流）→ 向きが変わる → 強まる → 弱まる、をくり返す
- 転流の時刻は、高潮・低潮の時刻とずれる（瀬戸ごとに違う）。宮窪瀬戸でのずれを書いた資料は見つからなかった（**不確か**）
- 大潮（新月と満月のころ）で最も速く、小潮（上弦・下弦のころ）で遅い [W潮汐]

### 目に見えるようす

- 「海に段差ができるほどの激しい潮流」[いよ観]
- 「渦巻く」「激しいしぶきを上げ白く泡立ちながら渦巻く光景」[いよ観]
- 流れに乗った船は「川に落ちた笹舟のようにくるくる回転する」[いよ観]
- 船折瀬戸：「船も折れるほどの潮流が川のように流れる」[検索:船折]
- 鵜島のまわりは「急潮と渦」[W鵜島]。来島海峡は「複雑な渦が形成され得る場所」[W来島]
- 潮目（流れの速い筋と遅い筋の境目）の線・泡の帯：資料の文章としては見つからなかった（**不確か**。写真で確かめること）

## 3. 岩の色と植物

- 芸予諸島の島は「どの島も平野部が狭く急峻な山あるいは丘陵地」[W芸予]
- 植物は「ほぼ広葉樹の代償植生」。塩づくりの燃料に木を大量に切ったためはげ山になり、そこに「繁殖力旺盛なアカマツが植えられていった」[W芸予]。→ 松が目立つ景色。ただし、塩づくりではげ山が広がったのが1570〜1600年ごろにもそうだったかは**不確か**
- 大島では大島石がとれる。大島石は花崗岩で、色は「灰黒色」。磨くと長石のため青みがかる（「青みかげ」）。粒は細かい〜中くらい（5 mm以下）。主に大島の北部（旧宮窪町）で切り出される [W大島石] [W大島]
- 花崗岩が風化すると「まさ土」と呼ばれる白っぽいざらざらした土になる [中国地質] → 岩肌や崖は白っぽい灰色、崩れた所は白っぽい黄土色
- 鵜島は、集落のある所をのぞいて周りが崖 [W鵜島]
